## Exit criteria

- run_gates.py executes every check runnable from the bag and skips fetch-only ones WITH a stated reason
- gate-board.json is machine-readable and lists every gate with pass/fail/skip
- exit code is non-zero if any non-skipped gate fails
- {'CI1': 'the runner itself has an H10 control (a seeded failing check must fail the board)'}
- {'CI2': 'a run from a clean bag reproduces the same board'}
