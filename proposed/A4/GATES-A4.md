## Gates

- [ ] S0: every node type and edge kind in the shipped graph is declared in
      `schema/obc.linkml.yaml`, and a node carrying an undeclared type fails
      validation.
  CHECK: `python3 harden/checks/check36_schema.py --db emitters/obc-mod.sqlite`
  EXPECT: `declared_type_share == 1.000` over all 27,421 node rows and
      `declared_kind_share == 1.000` over the 29,952 `ref` rows plus the `term`
      rows; exit 0. With one node's `type` set to a value absent from the
      `NodeType` enum, `declared_type_share < 1.000` and exit non-zero.

- [ ] S0-a (H10 control for S0, ratio gate): the S0 ratio is falsifiable.
  CHECK: `python3 harden/checks/check35_controls.py --db emitters/obc-mod.sqlite`
  EXPECT: entries `S0 declared types` and `S0 exit code` both read `ok` —
      untouched `real == 100.0% >= floor`, mutated `bad == 0.0% < floor`.
      Mutation `mut_inject_undeclared_type` targets the mechanism (the emitted
      `node.type` column) and never the ground truth (the enum in the schema).
      Registration is proposed in `schema/proposed/check35_A4_control.py.txt`;
      `harden/checks/check35_controls.py` is protected and was not edited.

- [ ] S0-b: the schema's own well-formedness — every `EdgeKind` permissible value
      declares a reverse-lookup label, every class is closed, and the three
      dual-encoding defects have exactly one declared representation each.
  CHECK: `python3 harden/checks/check36_schema.py --schema-only`
  EXPECT: exit 0. Runs with no database, so it is the one part of S0 that CAN be
      run in a data-less clone.

- [ ] S0-c (informational until B): conformance of today's emitted database to
      the declared schema.
  CHECK: `python3 harden/checks/check36_schema.py --db emitters/obc-mod.sqlite --strict`
  EXPECT: this is expected to FAIL today and that is the finding, not a bug.
      `pipeline/stage5_bind.py:81-83` writes the table binding into two fields
      (`parent` and `forming_part_of`) and `pipeline/emitters/stage15_sqlite.py`
      carries neither into SQLite. Fixing it at source is Track B's job, per
      `reports/remediation/PLAN.md`. Do not tick S0-c on A4.
